PortPilot is a local developer workstation for Mac.

## Show HN

**Title**
```
Show HN: PortPilot – kill :3000, query Postgres, format JSON in one Mac app
```

**Body**
```
I built PortPilot because my morning loop was: Activity Monitor (or lsof) to find who owns :3000, kill it, open a JSON formatter, then a DB client for local Postgres.

PortPilot is a local Mac app (also Windows) that keeps those in one window:

- Live table of listening ports (PID, CPU, memory, project path)
- Kill / restart, open localhost, jump to the terminal tab
- JSON / text tools and clipboard history
- Postgres, MySQL, SQLite, Redis, MongoDB (passwords in Keychain)

No account, no telemetry.

Mac (this is the build I want people on):
https://apps.apple.com/app/portpilot-desktop/id6801225932?mt=12

Source / Windows installer:
https://github.com/Shailesh200/PortPilot
```
